## 👋 Привет

Это мой повседневный рабочий стол на CachyOS: **bspwm + sxhkd**, Polybar,
picom, rofi, dunst и Alacritty. Конфиги собраны под ноутбук с
**AMD iGPU + NVIDIA** и под обычную работу: браузер, музыка, документы,
скриншоты и быстрый перебор обоев.

Всё, что можно автоматизировать, автоматизировано: палитра берётся из
текущей картинки, обои кэшируются под размер экрана, а дискретная NVIDIA
спит, пока её не попросят через `prime-run`.

## ✨ Возможности

### 🎨 Палитра из обоев

`config/theme/apply.py` читает текущие обои, вытаскивает из них цвета и
перекрашивает **Polybar, Alacritty, dunst, rofi, zathura, GTK-тему и рамки
bspwm**. При быстром переборе применяется только последняя картинка, а
палитра пересобирается один раз, когда вы остановились.

Обои кэшируются в размере экрана, поэтому переключение не декодирует
4K-оригинал каждый раз. Палитру можно пересобрать вручную:

```bash
~/.config/theme/apply.py            # по текущим обоям
~/.config/theme/apply.py --show     # только показать цвета
```

### 🖼️ Anime Wall — браузер артов

`Ctrl + Alt + A` — или пункт **Anime Wall** в rofi-лаунчере (`Super + Space`).
Открывается **поисковая строка для тегов** — сразу можно вбить, что ищешь,
и нажать Enter. Ищет по **Yande.re, Konachan, Danbooru и Gelbooru**.

- `Enter` начинает поиск, `Alt + F` — фильтры (рейтинг, score, размер,
  ориентация, сортировка), `Alt + P` — быстрая смена провайдера,
  `Alt + Q` — выход;
- `Tab` (или `Alt + T`) — подсказки тегов: недописанный тег ищется на
  буру, рядом с каждым показывается число постов. Выбранный тег
  подставляется в строку, так что можно набрать несколько через пробел
  (`landscape night`); `Tab` на пустом вводе показывает популярные
  теги;
- результаты показываются сеткой превью — можно спокойно скроллить мышью
  или стрелками. Если превью ещё догружаются, в строке состояния видно,
  сколько осталось, а `Alt + R` перерисовывает сетку без перехода
  на другую страницу;
- `Enter` по умолчанию **только сохраняет**; `Alt + A` — применить как обои;
  `Alt + S` — сохранить без смены обоев. Применённый арт копируется
  в `~/Images/Wallpaper_desktop`, поэтому его потом можно найти в селекторе
  обоев;
- `Alt + N` — следующая страница, `Alt + B` — предыдущая, `Alt + G` —
  выбрать страницу из списка (или ввести номер), `Alt + R` — обновить
  догрузившиеся превью, `Alt + Q` — выйти, `Esc` — обратно к поиску.
  Если страница пустая, браузер сам вернёт на последнюю с результатами;
- уже скачанные арты помечаются `✓`;
- файлы лежат в `~/Pictures/kiri-vault/<Провайдер>/` — у каждого бора
  своя папка;
- сеть ограничена таймаутами, результаты и превью кэшируются, скачивание
  идёт в фоне — интерфейс не замирает, даже если сервер недоступен.

### 🚀 Fastfetch с Асной

Логотип — не статичная картинка, а **ANSI-арт, который рендерится под размер
терминала**. Внутри используются полублоки с градиентами, а по краям силуэта
— брайль-точки, поэтому лицо и волосы остаются чёткими. Арт автоматически
уменьшается, чтобы список модулей не переносился, и исчезает на слишком
узком терминале.

Дополнительно показывается модуль **`Screen`** с текущей герцовкой монитора.
Готовый арт кэшируется в `~/.cache/fastfetch`, так что запуск мгновенный.

### 🧩 Rofi-апплеты

Всё управление собрано в rofi: обои, сеть, Bluetooth, буфер обмена,
скриншоты, звук, микрофон, питание, раскладка и шпаргалка по клавишам.
Темы rofi перекрашиваются вместе с остальным интерфейсом.

### 🔵 Bluetooth

`Super + Ctrl + B` открывает `bluetooth-menu`. Устройства показываются по
имени из BlueZ, а не по MAC-адресу, вместе с состоянием, активным кодеком и
зарядом. Для каждого устройства: подключить или отключить, спарить,
доверять, выбрать A2DP-кодек (SBC, SBC-XQ, AAC, LDAC, aptX, aptX HD — те,
что PipeWire предлагает для подключённого устройства), сделать его основным
аудиовыходом или забыть. В главном меню ещё скан и включение/выключение
адаптера.

LDAC ограничен 330 кбит/с (`mq`) в
`config/wireplumber/wireplumber.conf.d/51-bluetooth.conf`: комбо-карта
MediaTek MT7922 не держит 660 кбит/с (`sq`) и адаптивный `auto` даже с
выключенным Wi-Fi power save и автосоном USB. Если 330 кбит/с мало, чистая
альтернатива — AAC.

### 📊 Polybar

Столы bspwm, CPU, память, температура, GPU, now-playing, погода, батарея,
звук, сеть, раскладка и часы. `polybar-gpu` не опрашивает `nvidia-smi`,
пока карта спит, иначе она бы просыпалась каждые несколько секунд.

### 🎮 NVIDIA runtime PM

Установщик кладёт `nvidia-pm.conf`, udev-правила и включает сервисы NVIDIA,
если в системе есть карта. В простое `runtime_status` должен быть
`suspended`. Запуск на дискретной карте:

```bash
prime-run <команда>
```

### 📽️ Проектор / HDMI

HDMI-порт распаян на дискретную NVIDIA, а матрица и X-сессия работают на AMD
iGPU. Пока выходы NVIDIA не подключены к X как PRIME display-offload sink,
xrandr их вообще не видит.

Воткнуть кабель, сфокусировать презентацию и нажать `Super + Shift + O`
(`hdmi-present on --window`): HDMI включится, окно уедет туда во весь экран.
Тот же скрипт вызывается при логине в режиме `setup`, поэтому проектор,
подключённый до `startx`, подхватывает `dual_monitors.sh`.

Загруженный в X драйвер NVIDIA стоит около 2 Вт в простое: дискретка больше
не уходит в runtime suspend. `hdmi-gpu on|off` (нужен sudo и перелогин)
переключает между «HDMI работает» и «максимальная автономность».

### 🎙️ Whisper и медиа

`Super + D` — голосовой ввод, `Super + Shift + D` — запись лекции.
Модели Whisper не лежат в git, их скачивает `./install.sh --with-whisper`.
Медиа-клавиши работают через `playerctl` с запасным вариантом на `mpd`.
Латинские двойники, которые Whisper вставляет внутрь русских слов
(`привeт`), заменяются на кириллицу перед вводом.

### 🎵 Тексты песен в терминале

Наберите `music-tui` в любом терминале. Откроется окно без рамок и покажет
слова поющейся строки по одному-два за раз, крупными блочными буквами. Больше
ничего не рисуется: ни названия трека, ни подсказок.

Буквы — это настоящий жирный шрифт, отрисованный в пиксели и напечатанный
полублоками: поэтому они гладкие и всегда вписываются в окно. Для латиницы и
кириллицы берётся JetBrains Mono, для японских текстов — Noto Sans CJK. Окно
сохраняет цвета и фон терминала, так что совпадает с остальным рабочим столом.

Тексты берутся с [lrclib.net](https://lrclib.net), позиция — из любого
источника MPRIS через `playerctl` (браузер, mpv, spotifyd, ncspot), поэтому
никуда логиниться не нужно. Размер шрифта и окна — константы в начале
`bin/music-tui`.

Нужны `playerctl`, `python-pillow`, `python-fonttools`, шрифты JetBrains Mono и
`noto-fonts-cjk`.

## 🛠 Установка

```bash
git clone https://github.com/Kir1ght/bspwm-dotfiles.git
cd bspwm-dotfiles
./install.sh --dry-run   # посмотреть план
./install.sh
```

Одной командой:

```bash
curl -fsSL https://raw.githubusercontent.com/Kir1ght/bspwm-dotfiles/main/bootstrap.sh | bash
```

`install.sh` рассчитан на **Arch Linux и CachyOS**. Запускать его нужно от
обычного пользователя, sudo он спросит сам. Старые конфиги перед копированием
складываются в `~/.dotfiles-backup-*`.

| Флаг | Что делает |
|---|---|
| `--no-packages` | не ставить пакеты |
| `--no-config` | не копировать конфиги |
| `--no-gpu` | не трогать NVIDIA |
| `--no-firefox` | не трогать профиль Firefox |
| `--no-update` | не запускать `pacman -Syu` |
| `--with-whisper` | скачать модели whisper.cpp |
| `--with-apps` | поставить дополнительные приложения |
| `--with-extra` | AUR-утилиты, темы и `ly` |

`Builder/install.py` делает то же самое через меню.

## ⌨️ Клавиши

`Super` — это Win. Полная шпаргалка — `Super + Shift + /`, она собирается из
`sxhkdrc`.

| Комбинация | Действие |
|---|---|
| `Super + T` / `W` / `E` | терминал, Firefox, Thunar |
| `Super + Space` | rofi |
| `Super + Q` | закрыть окно |
| `Super + 1…9` | рабочий стол |
| `Super + Shift + 1…9` | отправить окно на стол |
| `Super + H/J/K/L` | фокус |
| `Super + Shift + H/J/K/L` | поменять окна местами |
| `Super + Ctrl + H/J/K/L` | размер окна |
| `Super + Ctrl + T` | псевдо-тайлинг: сохранить размер / вернуть обычный тайл |
| `Super + A` | плавающее ↔ тайл (всегда возвращает в тайл) |
| `Super + F` | полный экран ↔ состояние, из которого пришли |
| `Super + Alt + перетаскивание / клик` | сплит: бросить на половину или кликнуть для пометки и переноса |
| `Alt + Shift` | раскладка us/ru |
| `Ctrl + Shift + T` | случайные обои |
| `Ctrl + Alt + T` | выбрать обои |
| `Ctrl + Alt + L` | выбрать обои экрана блокировки |
| `Ctrl + Alt + A` | Anime Wall: поиск и скачивание артов |
| `Ctrl + Alt + R` | пересобрать палитру |
| `Print` | скриншот области |
| `Ctrl + Shift + L` | заблокировать экран |
| `Super + S` | выключить экран через 2 секунды |
| `Super + Alt + S` | разбудить матрицу, если осталась чёрной |
| `Super + D` / `Super + Shift + D` | Whisper: ввод, запись лекции |
| `Super + Ctrl + B` | Bluetooth: подключение, кодек, спарить, забыть |
| `Super + Shift + U` | тачпад: вкл/выкл автоотключение при мыши |
| `Super + Shift + O` | проектор: включить HDMI (NVIDIA) и развернуть окно на весь экран |

Медиа-клавиши и Fn-клавиши яркости тоже привязаны в sxhkd.

Раскладка `us/ru` настраивается в `bspwmrc` (и в `xinitrc` для startx):
`setxkbmap -layout us,ru -option grp:alt_shift_toggle`. Перезапуск `bspwmrc`
активную раскладку не сбрасывает: карта применяется только если загруженная
неверна.

Беспроводной донгл мыши тоже представляет собой клавиатурные устройства, и
при каждом переподключении Xorg заново применяет
`/etc/X11/xorg.conf.d/00-keyboard.conf` ко всем клавиатурам. Поэтому в этом
файле должны быть обе группы, иначе `ru` пропадает посреди сессии.
`install.sh` настраивает его командой
`localectl set-x11-keymap us,ru pc105 "" grp:alt_shift_toggle`. Для уже
установленной системы выполните ту же команду через `sudo`; она заработает
после следующего входа. `bin/xkb-layout-guard` — страховка для текущей
сессии: он ждёт события udev (без опроса) и восстанавливает раскладку после
hotplug.

Если `Alt + Shift` всё равно не работает, проверьте:

```bash
setxkbmap -query    # layout: us,ru, options: grp:alt_shift_toggle
xkb-switch -l      # должны быть us и ru
```

## 🖼️ Обои и палитра

На чистой установке ставится `Wallpaper_desktop/default.png`, пока вы не выберете
другие обои. Дальше bspwm восстанавливает последнюю картинку из `~/.fehbg`.

Обои разделены на две библиотеки — других папок скрипты не сканируют:

```text
~/Images/Wallpaper_desktop/      рабочий стол
~/Images/Wallpaper_lockscreen/   экран блокировки
```

```bash
~/bin/random_wallpaper              # случайные обои рабочего стола
~/bin/random_wallpaper --set PATH   # конкретная картинка
~/bin/random_wallpaper --lockscreen # случайные обои локскрина
~/bin/random_wallpaper --set PATH --lockscreen
~/bin/random_wallpaper --cache-all  # пересобрать кэш превью
~/bin/select-wallpaper              # rofi-селектор с превью
~/bin/select-wallpaper --lockscreen # селектор обоев локскрина
```

`select-wallpaper` (`Ctrl + Alt + T`) показывает сетку миниатюр, а не список
имён. `Enter` применяет выбранное, `Alt + V` открывает картинку на весь экран
(закрыть — `q`), `Alt + L` переключает между рабочим столом и локскрином,
`Esc` отменяет. Отдельная комбинация `Ctrl + Alt + L` сразу открывает селектор
локскрина. Превью кэшируются в `~/.cache/select-wallpaper/thumbs`, поэтому
повторное открытие почти мгновенное. После ручного изменения `sxhkdrc`
перезагрузите горячие клавиши командой `pkill -USR1 -x sxhkd` — иначе новые
комбинации начнут работать только после входа в систему.

Обычный селектор показывает только `Wallpaper_desktop`. Селектор локскрина
сначала показывает `Wallpaper_lockscreen`, а ниже — обои из
`Wallpaper_desktop` с пометкой `desktop/`. Если выбрать desktop-картинку,
она копируется в `Wallpaper_lockscreen` и сразу применяется к экрану
блокировки. Другие папки, включая `~/Downloads`, в сетку не подмешиваются.

Новую картинку можно положить в нужную библиотеку или применить напрямую:

```bash
~/bin/random_wallpaper --set ~/Downloads/new.png
~/bin/random_wallpaper --set ~/Downloads/lock.png --lockscreen
```

`random_wallpaper --set` импортирует файл в соответствующую библиотеку:
из `Downloads`/`/tmp` он **перемещается**, из остальных мест копируется.
Одинаковый файл не дублируется, а при совпадении имени с другим содержимым
создаётся `имя-2.png`. После импорта файл находится обычным сканированием
папки — никаких списков скачанных картинок нет.

`~/.current_wallpaper` и `~/.current_lockscreen` — стабильные симлинки на
текущие исходники. `random_wallpaper` обновляет их атомарно; `screen-lock`
читает именно `~/.current_lockscreen` (с запасным вариантом — первый файл
из `Wallpaper_lockscreen`). `~/.fehbg` по-прежнему хранит экранную копию
рабочего стола для быстрого восстановления при входе, а палитра строится
из неё. Смена обоев локскрина палитру не трогает.

Арты, применённые из Anime Wall (`Alt + A`), автоматически копируются
в `~/Images/Wallpaper_desktop` — в ту же библиотеку, которую листает
селектор, поэтому их можно выбрать потом.

### Anime Wall в терминале

У `anime-wall` есть и обычный CLI — удобно для скриптов и массового
скачивания:

```bash
# показать результаты JSON-ом
anime-wall -p yandere -t 'asuna_(sword_art_online)' --print

# скачать четыре пейзажа с Konachan
anime-wall -p konachan -t landscape -n 8 --download 4

# Gelbooru с фильтром по score
anime-wall -p gelbooru -t landscape --min-score 10
```

Настройки и API-ключи лежат в `~/.config/anime-wall/config.ini` (права
`600`). Yande.re и Konachan работают без ключей. **Gelbooru** требует
`api_key` и `user_id` — их можно ввести прямо в меню (`Gelbooru credentials…`),
и файл обновится сам. **Danbooru** иногда закрыт Cloudflare: если API
отвечает 403/503, откройте сайт в Firefox или подождите — Anime Wall
покажет ошибку и не зависнет.

`--download` складывает файлы туда же, в
`~/Pictures/kiri-vault/<Провайдер>/`. Если хочется только собирать
коллекцию, оставьте `on_enter = save` — это значение по умолчанию.

## 🌦️ Погода

Модуль берёт температуру с wttr.in. Город можно задать в
`~/.config/weather-city` строкой вида `Город,CC`. Файла в репозитории нет,
по умолчанию город определяется по IP. Если wttr.in путает одноимённые
места, допишите страну.

## 🖱️ Тачпад и мышь

Пока подключена любая мышь (USB, Bluetooth, донгл), тачпад **намеренно
выключен**. Убрали мышь — тачпад включается обратно через несколько секунд.
Так ладонь не задевает тачпад во время работы мышью.

Тачпад виден в XInput как два указателя с одинаковым именем оборудования
(`... Mouse` и `... Touchpad`). Они выключаются и включаются вместе:
если выключить только устройство со словом `touchpad`, парный «Mouse»
остаётся живым — из-за этого тачпад раньше продолжал работать при
подключённой мыши.

Это не поломка. Проверить состояние:

```bash
xinput list --short | grep -iE 'touchpad|uniw|synaptics|elan'
```

`slave pointer` — включён; `floating slave` — выключен.

Переключатель:

```bash
touchpad-autoswitch on      # автоматика включена (по умолчанию)
touchpad-autoswitch off     # тачпад всегда включён
touchpad-autoswitch toggle  # переключить
touchpad-autoswitch status  # показать состояние
```

С клавиатуры — `Super + Shift + U`.

Состояние хранится в `~/.local/state/touchpad-when-mouse.off`: есть файл —
автоматика выключена. Лог демона: `~/.local/state/touchpad-when-mouse.log`.

Устройства группируются по префиксу имени до `Mouse` / `Touchpad`, поэтому
на другой машине менять ничего не нужно. Виртуальные указатели игнорируются.
Выключенное устройство `xinput` показывает как `floating slave` и добавляет
к имени `∼`; демон это учитывает, иначе он не смог бы включить тачпад
обратно.

Мышь определяется и через XInput, и через ядро (`/proc/bus/input/devices`).
Беспроводной донгл может на мгновение пропасть из X, пока ядро его ещё
видит; проверка через ядро не даёт тачпаду включиться в этот момент.
Отсутствие мыши подтверждается несколько опросов подряд (три опроса, около
шести секунд), поэтому короткий провал донгла не возвращает тачпад.

### Заряд мыши

`vxe-battery` спрашивает у донгла VXE R1 SE+ заряд по hidraw и печатает
`87% (charging)`. `--percent` — только число для скриптов, `--json` — весь
ответ. Нужен `system/udev/71-vxe-mouse.rules` (его ставит `install.sh`),
чтобы вошедший пользователь мог открыть HID-интерфейс донгла.

### 🖐️ Жесты

Жесты работают через `touchegg` (только X11). Системный демон
`touchegg.service` включает установщик; клиентом сессии управляет
`touchpad-when-mouse.sh` — он останавливает его, пока подключена мышь.

| Жест | Действие |
|---|---|
| 3 пальца влево / вправо | следующий / предыдущий рабочий стол |
| 3 пальца вверх / вниз | фокус на окно выше / ниже |
| 4 пальца влево / вправо | перенести окно на следующий / предыдущий стол |
| 4 пальца вверх | полный экран / назад в предыдущее состояние |
| 4 пальца вниз | плавающее ↔ тайл |

Направления «естественные»: свайп влево — вперёд, вправо — назад. Жесты
относятся только к тачпаду: мышь и её донгл их не вызывают. Если подключена
мышь и тачпад выключен автоматикой, жесты не работают — это ожидаемо.
Включить тачпад: `Super + Shift + U` или `touchpad-autoswitch off`.

Touchégg читает тачпад через libinput, поэтому одного `xinput disable`
недостаточно: демон останавливает ещё и клиент сессии и снова запускает его,
когда мышь отключают. Трогается только этот клиент — сервис
`touchegg --daemon` продолжает работать. Пока мышь подключена, тачпад и
жесты не принимают ничего.

Конфиг: `~/.config/touchegg/touchegg.conf`. После правки перезапустите
клиент: `pkill -f '[t]ouchegg$'` (демон запустит его снова через пару секунд,
если мышь не подключена) или запустите `touchegg` из терминала после
`touchpad-autoswitch off`.

### 🪟 Окна: обычный bspwm + сплит как в Niri

Обычное `Super` + мышь оставляет штатное поведение bspwm:

| Мышь | Действие |
|---|---|
| `Super + ЛКМ` | двигает плавающее окно; тайловые окна просто меняет местами (обычное перетаскивание bspwm) |
| `Super + СКМ` | меняет размер тайлового окна за границу с соседом |
| `Super + ПКМ` | меняет размер тайлового окна за ближайший угол |

Изменение размера тайлового окна двигает границу, которую оно делит с
соседом. У окна, занимающего весь монитор, такой границы нет: сначала
сделайте его псевдо-тайловым (`Super + Ctrl + T`), и тогда размер меняется
мышью или через `Super + Ctrl + H/J/K/L`. Окна с фиксированным размером
(диалоги) сохраняют свой размер — так задумано.

`Super + A` и `Super + F` используют `~/.local/bin/bspwm-toggle-state`, а не
собственные `~floating` / `~fullscreen` bspwm. Переключатель `~STATE` помнит
только предыдущее состояние, поэтому после полноэкранного режима `Super + A`
прыгал между плавающим и полноэкранным и никогда не возвращался в тайл.
Хелпер выбирает цель явно: плавающее всегда возвращается в обычный тайл, а
выход из полного экрана восстанавливает состояние, из которого пришли. Так же
он работает для тайловых, псевдо-тайловых, плавающих, полноэкранных окон и
диалогов с фиксированным размером. Жесты тачпада на 4 пальца вызывают тот же
хелпер.

Удерживайте **`Super + Alt`**, чтобы ставить окна как в Niri, а не менять
местами:

- `Super + Alt + перетаскивание` — тащите окно на левую, правую, верхнюю
  или нижнюю половину другого окна. Половина под курсором подсвечивается,
  и при отпускании окно встаёт туда;
- `Super + Alt + клик` по окну — пометить его, затем `Super + Alt + клик`
  по половине другого окна — окно встанет туда. Тащить вообще не нужно, на
  тачпаде это гораздо удобнее. Повторный клик по помеченному окну снимает
  пометку;
- бросок на пустое место или на само окно ничего не делает;
- одновременно помечено только одно окно;
- плавающее или псевдо-тайловое окно тоже можно поставить: оно станет
  обычным тайлом, старый плавающий/псевдо-размер сбрасывается. Плавающие и
  полноэкранные окна нельзя использовать как *цель*, а полноэкранное окно
  игнорируется, пока вы не выйдете из полноэкранного режима;
- цель — окно под курсором, поэтому сплит работает и между мониторами, а
  помеченное окно может лежать даже на другом рабочем столе;
- на рабочем столе в режиме monocle используйте клавиатурный вариант ниже:
  дерево меняется, но увидеть сплит можно только после выхода из monocle —
  уведомление об этом скажет (мышью нельзя навести на другое окно, когда все
  они перекрываются);
- если перетаскивание прервать, подсветка половины снимается.

`Super + Z + клик` (или любая буква вместе с кнопкой мыши) в sxhkd
привязать нельзя: в мышиной комбинации допустимы только настоящие
модификаторы. `Super + Alt` выбран потому, что это тот же префикс, что и у
клавиатурного сплита ниже.

Тот же результат с клавиатуры — пометить окно, перейти на цель и нажать
половину. Окно встаёт сразу, поэтому предпросмотра и лишнего нажатия нет:

1. `Super + Alt + M` — пометить окно, которое хотите перенести.
2. Перейти на окно-цель обычными клавишами фокуса.
3. `Super + Alt + H/J/K/L` — поставить помеченное окно в левую / нижнюю /
   верхнюю / правую половину цели.
4. `Super + Alt + C` — снять зависший преселект, оставшийся от мыши или
   ручного `bspc node -p`; клавиатурный сценарий его обычно не оставляет.

Пример: пометить маленькое окно, встать на большое окно слева, нажать
`Super + Alt + K` (верхняя половина) — область большого окна разделится
сразу: маленькое займёт верхнюю половину, большое — нижнюю. Пометка второго
окна снимает пометку с первого, так что помечено всегда то окно, которое вы
отметили последним.

Скрипты: `~/.local/bin/bspwm-drag-split` (мышь и тачпад) и
`~/.local/bin/bspwm-split` (клавиатура, есть `status` и `--help`).

## 🩺 Если что-то не работает

### Вошли, а рабочий стол пустой

`bspwm` запускает `~/.config/bspwm/bspwmrc` напрямую, поэтому файл **должен
быть исполняемым**. Без бита выполнения bspwm пропускает его *молча*: ни
обоев, ни polybar, ни picom, ни горячих клавиш — только пустой экран, и
кажется, что сессия не запустилась. Проверить и исправить:

```bash
ls -l ~/.config/bspwm/bspwmrc     # нужно -rwxr-xr-x
chmod 755 ~/.config/bspwm/bspwmrc
```

Затем выйдите и войдите снова. Бит снимают копирование конфигов через
`install -m644`, восстановление из резервной копии и распаковка
`git archive`. `install.sh` ставит его сам и прерывается, если его нет.

### Чёрный экран после входа

Предыдущая сессия может оставить матрицу в DPMS-off: текстовый консоль тогда
остаётся чёрным, хотя машина работает, и перезагрузка может не помочь
(запрошенная яркость не меняется, поэтому драйвер её не применяет заново).
`screen-wake` записывает читаемое значение и снимает DPMS. Он вызывается из
`~/.bash_profile` при входе в консоль, из `bspwmrc` при старте X и из
`~/.xinitrc` после выхода из bspwm; вручную — `Super + Alt + S`.

## 📝 Мелочи

- Только Arch/CachyOS и X11, Wayland не поддерживается.
- `hz-toggle` и `dual_monitors.sh` завязаны на конкретное железо. На другой
  машине сначала посмотрите `xrandr --query`.
- Модели Whisper не лежат в git, их скачивает `--with-whisper`.
- picom запускается с профилем `1.conf`. Если включить второй профиль,
  скриншоты всё равно не будут размываться: `slop` есть в исключениях.
  В профиле включены короткие анимации открытия/закрытия и смены раскладки;
  чтобы их выключить, закомментируйте блок `animations` в `1.conf`
  и перезапустите picom.
- Throne получает `CAP_NET_ADMIN` через pacman-hook, поэтому TUN работает
  без запросов root после обновлений.
- GTK-тема `Dynamic` — перекрашенная копия Dracula. Открытые окна подхватят
  цвета после перезапуска.
- `ly` ставится только с `--with-extra`.
- `v2raya-bin` (v2rayA) вместе с ядром `xray` и `upscayl-bin` (Upscayl)
  ставятся по умолчанию. Сервис v2rayA включается отдельно:
  `sudo systemctl enable --now v2raya`.
- `anime-wall` использует только стандартную библиотеку Python; для
  ANSI-арта fastfetch нужен `python-pillow`.
